# 分阶段实现路线

## Phase 0: 工程骨架

目标：

- 建立 Python/C++ 混合工程
- 明确数据模型
- 确立测试与构建流程

交付：

- 基础目录
- CMake + pybind11 构建
- Python 入口
- 架构文档

风险：

- 目录结构不稳定导致反复重构

## Phase 1: 最小可用 FEM 内核

目标：

- T3 单元
- 平面应力/应变材料
- 单元刚度
- 全局装配
- 位移求解
- 单元应力恢复

交付：

- 单元测试
- Patch test
- 拉伸板算例

风险：

- 单元局部坐标、Jacobian 与 B 矩阵实现错误
- 边界条件处理引入奇异矩阵

## Phase 2: 求解器与性能

目标：

- 稀疏矩阵组装
- Eigen 稀疏求解器
- Python/C++ 数据传输优化

交付：

- COO -> CSR/稀疏矩阵
- Solver 配置接口

风险：

- 过早优化导致接口混乱

## Phase 3: GUI 工程化

目标：

- 模型树
- 参数面板
- 网格显示
- 变形图/云图

交付：

- Qt 主窗口
- 结果可视化

风险：

- 把可视化逻辑硬编码进求解流程

## Phase 4: AI 增强

目标：

- 自然语言题目结构化解析
- 网格与单元建议
- 结果解释生成

交付：

- AI 输入/输出结构
- Prompt 模板
- 可追溯的解释报告

风险：

- 输出不可验证
- AI 与物理规则冲突

## Phase 5: 优秀项目/论文化

目标：

- 形成标准算例对比
- 形成模块化实验平台
- 总结 AI + FEM 的创新点

交付：

- 实验报告
- 对比图表
- 论文式技术说明
